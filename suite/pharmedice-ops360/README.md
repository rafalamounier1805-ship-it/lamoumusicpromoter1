Status: **EM DESENVOLVIMENTO**.

Este diretório registra o produto PHARMÉDICE OPS 360 dentro do ecossistema LAMOU IA sem promover protótipos visuais rejeitados para produção.

- contrato de registro na Central LAMOU IA;
- canais SIMULATION / HOMOLOGATION / REAL separados;
- governança `no_fake_actions`, LGPD, RBAC/ABAC, auditoria e Test Mode.

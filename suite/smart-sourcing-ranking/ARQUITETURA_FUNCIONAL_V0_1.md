# Arquitetura Funcional V0.1

Fluxo: Entrada/persona → Criar necessidade → Requirement Engine → Measurement Capture → Prioridades/constraints → Match → Propostas → Smart Flex → Negociação → Congelamento → Ranking explicável → Contratação DEMO → Pós-venda → Trust/Reputation → Market Intelligence.

## Cliente
Início; Criar Ranking; Meus Rankings; Negociações; Favoritos; Benefícios; Local+; Histórico; Fidelidade; Perfil & Preferências.

## Fornecedor
Início; Oportunidades; Produtos/Serviços; Capacidades; Benefícios; Parcerias; Lojas/Unidades; Propostas; Negociações; Pedidos/Contratos; Reputação; Rankings; Inteligência Comercial.

## Dados
users/profiles; organizations/providers; provider_profiles; physical_units; points_of_service; categories; requirement_schemas; needs/rankings; criteria; criteria_versions; measurements; offers/proposals; proposal_versions; negotiation_rounds; benefits; partner_benefits; matches; scores; score_explanations; orders/contracts; deliveries; evaluations; trust_events; reputation_snapshots; loyalty_relationships; audit_logs.

## Regras
- obrigatório é eliminatório;
- Smart Flex nunca muda regra sem aceite;
- critérios são versionados após abertura da disputa;
- monetização não compra score;
- preferência por fornecedor é peso explícito;
- dinheiro e conveniência são separados;
- medição visual sempre mostra confiança;
- DEMO/SIMULAÇÃO sempre identificado.
